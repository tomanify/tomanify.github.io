درباره Tebaro و تغییر نام از Tomanify

Tebaro یک پروژه مستقل و متن‌باز برای کمک به قیمت‌گذاری محصولات خارجی در WordPress/WooCommerce است.

عدم وابستگی: Tebaro، که پیش‌تر با نام Tomanify منتشر می‌شد، هیچ ارتباط سازمانی، تجاری، مالکیتی یا همکاری با tomanify.com، صرافی‌ها، کارگزاری‌ها، پلتفرم‌های رمزارز یا خدمات انتقال پول ندارد.

چرا نام عمومی عوض شد؟

نام Tebaro برای هویت عمومی پروژه انتخاب شده، اما شناسه‌های فنی قدیمی تغییر نکرده‌اند تا نصب‌های قبلی بدون مهاجرت پرریسک ادامه پیدا کنند. بنابراین مسیر WordPress.org، textdomain و شورتکد ممکن است هنوز نام tomanify را داشته باشند.

این سایت چه چیزی را مستند می‌کند؟

رفتار نهایی افزونه، معماری منبع رسمی + ضریب کالیبراسیون، حالت آفلاین و دستی، مهاجرت از JSON قدیمی، قیمت‌گذاری، Cron، بکاپ، امنیت و رابط فارسی/انگلیسی.
