تنظیمات پیشرفته Tebaro

تنظیمات پیشرفته برای کنترل حساسیت تغییر، CAGR آفلاین، Reset و رفتارهای نگهداری هستند؛ ضریب کالیبراسیون در نسخه جدید متعلق به تب Sources است، نه Advanced.

Change sensitivity threshold

برای کنترل رفتارهایی که نسبت به تغییرات بزرگ حساس‌اند استفاده می‌شود. آن را با Margin محصول اشتباه نگیرید؛ Margin بخشی از فرمول قیمت هر محصول است.

CAGR و Offline

Offline از مرجع رسمی USD ذخیره‌شده و زمان آن، CAGR، نسبت‌های رسمی snapshot و ضریب local/cached استفاده می‌کند. تنظیم CAGR باید واقع‌بینانه و قابل بازبینی باشد.

Factory Reset

Reset تنظیمات فعال و stateهای مشتق‌شده را به پیش‌فرض برمی‌گرداند؛ URLهای منابع دوباره خالی می‌شوند، Auto coefficient خاموش می‌شود و ضریب دستی به مقدار پیش‌فرض برمی‌گردد.
