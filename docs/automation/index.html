Update Rates و Cron Scheduling در Tebaro

دو راه اصلی برای تازه‌سازی مقادیر تبدیل دارید: اجرای دستی برای بررسی فوری و Cron برای اجرای دوره‌ای.

Update Rates

برای تست تنظیمات یا نیاز فوری استفاده می‌شود. در حالت migration hold این دکمه نباید دور زدن توقف ایمنی را ممکن کند و refresh به‌صورت کنترل‌شده متوقف می‌شود.

Cron Scheduling

در اجرای زمان‌بندی‌شده همان resolver منبع استفاده می‌شود. URLهای رسمی یا ضریب فقط در حالت‌هایی که شبکه مجاز است خوانده می‌شوند؛ Offline و Manual شبکه ندارند.

نکته قیمت محصولات

هر refresh موفق ممکن است queue محاسبه محصولات foreign را راه بیندازد. lock و chunk برای جلوگیری از اجرای هم‌زمان سنگین در hosting اشتراکی استفاده می‌شوند.
