بکاپ و انتقال تنظیمات Tebaro

Export/Import تنظیمات کاربر را جابه‌جا می‌کند، اما stateهای مشتق‌شده مانند provenance، cache ضریب و snapshot آفلاین را منبع حقیقت قابل حمل نمی‌داند.

چه چیزهایی قابل انتقال‌اند؟

  • Source mode
  • URLهای رسمی HTTPS
  • Manual conversion values
  • Manual fallback coefficient
  • Auto coefficient enabled + Feed URL
  • زبان، واحد، Cron، CAGR و تنظیمات شورتکد

چه چیزهایی authoritative backup نیستند؟

  • coefficient feed state/cache
  • rate provenance
  • offline ratio snapshot
  • migration diagnostics

اگر backup در حالت migration hold گرفته شود، خود hold برای ایمنی می‌تواند حفظ شود.

JSON قدیمی

Export جدید URL قدیمی JSON را صادر نمی‌کند. Import بکاپ قدیمی می‌تواند آن را فقط به‌عنوان داده legacy غیرفعال بشناسد و هرگز نباید دوباره آن endpoint را request کند.
