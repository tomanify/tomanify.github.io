پاک‌سازی کش بعد از تغییر قیمت در Tebaro

Purge اختیاری است و برای این طراحی شده که بعد از بازنویسی قیمت، صفحه همان محصول سریع‌تر نسخه تازه را نشان دهد.

پیش‌فرض امن

این قابلیت پیش‌فرض خاموش است. وقتی فعال باشد فقط URLهای همان host مجازند و نباید به endpointهای خارجی تبدیل شود.

چه زمانی لازم است؟

اگر لایه cache سایت باعث می‌شود قیمت ذخیره‌شده جدید دیر در frontend دیده شود. در بسیاری از فروشگاه‌ها افزونه cache اختصاصی خودش purge را مدیریت می‌کند و نیازی به فعال‌سازی این گزینه نیست.
