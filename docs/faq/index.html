سوالات پرتکرار درباره Tebaro

FAQ اصلی Tebaro

Tebaro چیست و چه نسبتی با Tomanify دارد؟

Tebaro نام عمومی جدید Tomanify است. شناسه‌های فنی tomanify برای سازگاری آپدیت‌ها حفظ می‌شوند.

آیا Tebaro نرخ خرید و فروش ارز اعلام می‌کند؟

خیر. Tebaro ابزار قیمت‌گذاری/تبدیل محصول است و خروجی آن برای محاسبه قیمت کالا به‌کار می‌رود.

آیا JSON نرخ بازار آزاد هنوز پشتیبانی می‌شود؟

در runtime جدید خیر. JSON چندارزی و provider selection بازنشسته شده‌اند.

Automatic fallback چه ترتیبی دارد؟

Official-rate estimate → Offline estimate → Manual conversion values؛ اگر هیچ‌کدام usable نباشند مقدار فعلی حفظ می‌شود.

آیا فید coefficient اجباری است؟

خیر. Auto coefficient پیش‌فرض خاموش و URL خالی است. ضریب دستی همیشه fallback مدیر است.

Offline اینترنت مصرف می‌کند؟

خیر. Offline هیچ request خارجی ندارد.

آیا داده مشتری یا سفارش به بیرون ارسال می‌شود؟

خیر. درخواست‌های source/coefficient شامل داده مشتری، سفارش، محصول، analytics یا telemetry نیستند.

شورتکد بعد از تغییر نام چیست؟

برای compatibility همچنان [tomanify_rates] است.

چرا صفحه WordPress.org هنوز tomanify است؟

slug افزونه برای سازگاری و مسیر آپدیت ثابت مانده و فقط نام نمایشی به Tebaro تغییر می‌کند.
