امکانات Tebaro برای WooCommerce

تمرکز Tebaro روی یک کار مشخص است: تبدیل هزینه خارجی محصول به پایه تومان و نگهداری قیمت واقعی ووکامرس به‌شکل قابل اتکا.

موتور قیمت‌گذاری

  • پشتیبانی از USD، EUR، AED، TRY و CNY
  • قیمت خرید خارجی + Margin برای هر محصول
  • ذخیره پایه نهایی به تومان
  • گرد کردن به نزدیک‌ترین ۱۰۰۰ تومان
  • تغییر نمایش تومان/ریال بدون refetch

منابع تبدیل

  • Automatic fallback: Official → Offline → Manual
  • URLهای رسمی فقط با ورود مدیر و HTTPS
  • ضریب دستی همیشه در اختیار مدیر
  • فید ضریب خودکار اختیاری و پیش‌فرض خاموش
  • Offline و Manual بدون درخواست خارجی

مدیریت فروشگاه

  • Update Rates دستی
  • Cron Scheduling
  • صف/بچ برای محصولات زیاد
  • پاک‌سازی کش اختیاری same-host
  • Backup/Import با اعتبارسنجی

رابط و نمایش

  • زبان مستقل site/en_US/fa_IR
  • RTL/LTR مستقل از زبان وردپرس
  • شورتکد [tomanify_rates]
  • نمایش provenance محلی بدون درخواست فرانت‌اند
  • تور راه‌اندازی داخل افزونه
