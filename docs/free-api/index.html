API رایگان نرخ ارز؟ معماری جدید Tebaro از نرخ چندارزی استفاده نمی‌کند

اگر با عبارت‌هایی مثل «API رایگان نرخ ارز برای ووکامرس» به این صفحه رسیده‌اید، تفاوت مهم نسخه جدید Tebaro این است که افزونه دیگر JSON شامل نرخ USD/EUR/AED/TRY/CNY دریافت نمی‌کند.

فید جدید فقط یک عدد می‌دهد

فید خودکار فقط یک estimate calibration coefficient بدون واحد و متادیتای محدود منتشر می‌کند. این عدد با مشاهده رسمی ریالی داخل افزونه ترکیب می‌شود.

{
  "schema_version": 1,
  "coefficient": 1.525058,
  "generated_at": "2026-10-07T00:00:00Z",
  "valid_until": "2026-10-08T00:00:00Z",
  "method": "median_of_currency_ratios_v1",
  "sample_count": 5,
  "status": "ok"
}

چه چیزهایی عمداً در فایل نیست؟

  • نرخ USD/EUR/AED/TRY/CNY
  • نام Provider یا سایت منبع
  • URL منبع
  • داده خام یا log جمع‌آوری
  • اطلاعات مشتری، سفارش یا محصول

لینک نهایی فید عمومی Tebaro

فایل نهایی عمومی پروژه با نام coefficient.json در مخزن زیر قرار می‌گیرد:

مشاهده coefficient.json در GitHub

https://raw.githubusercontent.com/tebaro-wp/coefficient-index/main/coefficient.json

استفاده اختیاری است

Auto coefficient در افزونه پیش‌فرض خاموش و URL پیش‌فرض خالی است. مدیر می‌تواند این endpoint یا هر فید HTTPS سازگار دیگری را انتخاب کند. افزونه برای Offline و Manual هیچ درخواست خارجی نمی‌فرستد.

اعتبار و fallback

Payload جدید باید تازه و معتبر باشد. افزونه ضریب last-good را در یک بازه grace محدود نگه می‌دارد و پس از آن به ضریب دستی مدیر برمی‌گردد. تغییر مشکوک و بزرگ نیز با guard مستقل رد می‌شود.
