نصب و راه‌اندازی Tebaro در WooCommerce

Tebaro به‌صورت in-place روی شناسه فنی Tomanify ادامه پیدا می‌کند، بنابراین نصب‌های قدیمی نیاز به افزونه دوم ندارند.

نصب تازه

از WordPress.org افزونه را نصب کنید. URLهای source و coefficient در نصب تازه خالی هستند و تا زمانی که مدیر آن‌ها را تنظیم نکند درخواست خارجی مرتبطی انجام نمی‌شود.

ارتقا از Tomanify قدیمی

JSON قدیمی به منبع Official نگاشت نمی‌شود. اگر سایت به JSON قدیمی وابسته بوده، مقادیر فعلی برای جلوگیری از تغییر ناگهانی قیمت حفظ می‌شوند و بسته به وضعیت Manual ممکن است migration hold نمایش داده شود.
