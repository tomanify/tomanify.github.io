شروع سریع Tebaro در چند دقیقه

برای شروع نیازی به JSON نرخ بازار آزاد ندارید. مسیر پیشنهادی نسخه جدید از منابع رسمی و ضریب دستی/اختیاری شروع می‌شود.

۱) حالت منبع

Automatic fallback را انتخاب کنید تا زنجیره Official → Offline → Manual فعال باشد. اگر فقط یک رفتار مشخص می‌خواهید، هرکدام را جداگانه انتخاب کنید.

۲) منابع رسمی

در تب Sources فقط URLهای HTTPS مورداعتماد خودتان را وارد کنید. هیچ URL پیش‌فرضی در افزونه وجود ندارد.

نمونه لینک‌های رسمی

۳) ضریب

Manual fallback coefficient را نگه دارید یا در صورت تمایل Auto coefficient را فعال و URL فید سازگار وارد کنید. فید همراه Tebaro در صفحه ضریب توضیح داده شده است.

راهنمای ضریب خودکار

۴) Update Rates و محصول

یک بروزرسانی دستی اجرا کنید، سپس در محصول موردنظر حالت foreign را فعال کنید، ارز، قیمت خارجی و Margin را وارد و ذخیره کنید.
