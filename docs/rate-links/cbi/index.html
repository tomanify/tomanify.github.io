لینک‌های رسمی هر ارز برای Tebaro

این صفحه یک فهرست اطلاع‌رسانی برای کپی‌کردن URLهای اختیاری RSS/XML بانک مرکزی است. Tebaro این آدرس‌ها را داخل افزونه از پیش وارد نمی‌کند؛ مدیر سایت در صورت تمایل، لینک هر ارز را خودش در فیلد مربوط در تب Sources قرار می‌دهد.

حریم خصوصی و ایمنی: بازکردن این صفحه هیچ درخواستی به endpointهای بانک مرکزی ارسال نمی‌کند. آدرس‌ها فقط به‌صورت متن نمایش داده می‌شوند و دکمه «کپی لینک» فقط از قابلیت محلی Clipboard مرورگر استفاده می‌کند. هیچ tracking، telemetry یا ارسال داده‌ای برای این کار وجود ندارد.

مشاهده رسمی به ریال خوانده می‌شود و در حالت Official-rate estimate با ضریب مؤثر به مقدار تخمینی تومان تبدیل می‌شود. این صفحه خودش نرخ ارز منتشر یا محاسبه نمی‌کند و هیچ URLی را در تنظیمات افزونه ذخیره نمی‌کند.
