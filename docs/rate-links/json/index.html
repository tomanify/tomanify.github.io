لینک نمونه JSON بازار آزاد

این صفحه برای کپی سریع یک لینک نمونه اختیاری JSON ساخته شده است. این آدرس را فقط زمانی وارد کنید که می‌خواهید از همین منبع به‌عنوان منبع نرخ بازار آزاد استفاده کنید.

لینک قابل کپی برای فیلد Free market JSON URL

https://raw.githubusercontent.com/rate-json/default/main/data.json

مسیر استفاده: پیشخوان وردپرس ← Tomanify ← Sources ← فیلد Free market JSON URL

چرا این لینک از قبل داخل افزونه نیست؟

برای امنیت، شفافیت و رعایت قوانین مخزن وردپرس، Tomanify هیچ منبع نرخ خارجی را به‌صورت پیش‌فرض داخل تنظیمات ذخیره یا فعال نمی‌کند. مدیر سایت باید منبع مورد نظر را آگاهانه انتخاب کند و خودش لینک HTTPS را در فیلد مربوط قرار دهد.

اگر API یا فایل JSON اختصاصی دارید، به‌جای این نمونه می‌توانید لینک همان منبع را وارد کنید؛ فقط خروجی باید با ساختار سازگار Tomanify و مقادیر تومانی برگردد.
