Factory Reset و حذف Tebaro

Reset تنظیمات را به حالت پیش‌فرض می‌برد؛ Uninstall می‌تواند سبک یا کامل باشد، اما حذف داده محصول فقط با انتخاب صریح مدیر انجام می‌شود.

Factory Reset

URLهای منابع را خالی، Auto coefficient را خاموش، stateهای مشتق‌شده و legacy را پاک و Source mode را به پیش‌فرض امن برمی‌گرداند.

Uninstall

Woo _price و _regular_price نباید صرفاً به‌خاطر حذف افزونه پاک شوند. حذف metaهای اختصاصی محصول فقط وقتی مجاز است که گزینه delete-all-data صریحاً فعال باشد.
