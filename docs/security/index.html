امنیت، حریم خصوصی و سرویس‌های خارجی Tebaro

درخواست خارجی فقط برای URLهای HTTPS است که مدیر صریحاً تنظیم می‌کند. Tebaro هیچ tracking یا telemetry داخلی ندارد و داده مشتری/سفارش/محصول را برای این درخواست‌ها ارسال نمی‌کند.

دو خانواده درخواست ممکن

  1. URLهای رسمی هر ارز که مدیر در Sources وارد کرده است.
  2. فید اختیاری یک ضریب کالیبراسیون scalar که مدیر فعال و URL آن را وارد کرده است.

Offline و Manual هیچ درخواست خارجی ندارند.

فید ضریب چه داده‌ای می‌گیرد؟

افزونه فقط فایل عمومی coefficient را GET می‌کند. سفارش، ایمیل، نام مشتری، محصول، analytics یا telemetry در request body ارسال نمی‌شود.

مخزن عمومی ضریب Tebaro

URLها پیش‌فرض خالی‌اند

افزونه هیچ provider URL پنهان یا fallback URL hardcoded ندارد. مدیر باید URL HTTPS را خودش وارد کند.

مسئولیت منبع

مدیر باید اطمینان داشته باشد استفاده از URL یا سرویس انتخابی با شرایط استفاده و قوانین مربوط سازگار است. مستندات Tebaro مجوز استفاده از سرویس ثالث ایجاد نمی‌کند.

این فایل فقط coefficient و metadata محدود دارد و حاوی نرخ ارز، Provider، URL منبع یا داده خام نیست.
