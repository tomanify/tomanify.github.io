شورتکد Tebaro برای نمایش مقادیر تبدیل

برای سازگاری فنی، نام شورتکد همچنان [tomanify_rates] است.

[tomanify_rates]

چه چیزی نمایش داده می‌شود؟

یک کارت محلی شامل عنوان، واحد، زمان آخرین بروزرسانی و ارزهای انتخابی. در صورت وجود provenance، منبع به شکل محافظه‌کارانه مثل «Official estimate» یا «Offline estimate» نمایش داده می‌شود.

چه چیزی نمایش داده نمی‌شود؟

Provider خارجی، لوگو/credit اجباری، Powered by، لینک تبلیغاتی یا نرخ خرید/فروش رسمی. JavaScript فرانت‌اند نیز هیچ درخواست شبکه‌ای برای نرخ یا ضریب انجام نمی‌دهد.

متن عمومی پیشنهادی: «مقادیر تخمینی برای محاسبه قیمت کالا؛ این مقادیر نرخ خرید یا فروش ارز نیستند.»
