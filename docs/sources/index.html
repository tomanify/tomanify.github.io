منابع تبدیل و ضریب کالیبراسیون در Tebaro

نسخه جدید سه خانواده واقعی دارد: Official-rate estimate، Offline estimate و Manual conversion values. حالت Automatic فقط ترتیب fallback را مدیریت می‌کند.

Automatic fallback

Official-rate estimate
↓ unavailable
Offline estimate
↓ unavailable
Manual conversion values
↓ unavailable
No-op: keep current stored values

JSON چندارزی قدیمی در این زنجیره وجود ندارد.

Official-rate estimate

مدیر می‌تواند برای هر ارز یک URL رسمی HTTPS وارد کند. مقدار رسمی به ریال خوانده می‌شود و با ضریب مؤثر به مقدار تخمینی تومان تبدیل می‌شود:

official_rial × coefficient ÷ 10

اگر هیچ URL رسمی معتبر نباشد، حالت Auto سراغ Offline می‌رود.

ضریب دستی و خودکار

فیلد Manual fallback coefficient منبع کنترل مدیر است. فید خودکار اگر فعال شود فقط یک ضریب بدون واحد را می‌خواند و هیچ‌وقت مقدار دستی را overwrite نمی‌کند.

جزئیات ضریب خودکارکپی لینک فید Tebaro

Offline و Manual

Offline هیچ درخواست شبکه‌ای انجام نمی‌دهد و از مرجع رسمی ذخیره‌شده، snapshot نسبت‌های رسمی، CAGR و ضریب cached/manual استفاده می‌کند. Manual مستقیماً مقدار تبدیل تومانی را از مدیر می‌گیرد و ضریب در آن کاربردی ندارد.

JSON بازار آزاد قدیمی چه شد؟

فید چندارزی قدیمی بازنشسته شده و دیگر در runtime درخواست نمی‌شود. در ارتقا، سایت‌های وابسته به آن برای جلوگیری از تغییر ناگهانی قیمت یا به Manual امن منتقل می‌شوند یا در حالت توقف مهاجرت قرار می‌گیرند تا مدیر تصمیم بگیرد.

فید همراه اختیاری Tebaro

برای کسانی که می‌خواهند از فید ضریب همراه پروژه استفاده کنند، مقصد نهایی عمومی این است. این URL در افزونه prefill نمی‌شود و استفاده از آن اختیاری است:

https://raw.githubusercontent.com/tebaro-wp/coefficient-index/main/coefficient.json
