رفع اشکال Tebaro

مشکل‌ها را از منبع و coefficient شروع کنید، سپس ذخیره مقدارهای تبدیل، queue محصولات و cache فروشگاه را بررسی کنید.

Official در دسترس نیست

URL HTTPS، پاسخ سرویس، parse مقدار IRR و اینکه حداقل یک ارز معتبر برگشته باشد را بررسی کنید. اگر هیچ مشاهده رسمی معتبر نباشد، افزونه نباید فقط برای coefficient یک درخواست جداگانه بی‌فایده بزند.

Coefficient fallback

در Auto coefficient، payload باید schema دقیق و timestamp معتبر داشته باشد. cache معتبر تا grace محدود استفاده می‌شود و پس از آن manual fallback.

محصول تغییر نکرده

مطمئن شوید محصول foreign=1 است، ارز پشتیبانی‌شده دارد و rate_tmn مثبت ذخیره شده است. queue/chunk نیز باید فرصت اجرا داشته باشد.

قیمت 10× شده

پایه داخلی همیشه تومان است. تغییر واحد باید فقط baseline را به ریال ×10 کند؛ منبع رسمی نیز ابتدا IRR است و formula coefficient شامل ÷10 می‌شود.

سوالات متداول

آیا می‌توان JSON قدیمی را دوباره فعال کرد؟

در معماری جدید خیر؛ JSON چندارزی legacy عمداً از runtime حذف شده است.

اگر فید ضریب قطع شود فروشگاه می‌خوابد؟

خیر؛ cache last-good محدود و سپس ضریب دستی fallback وجود دارد. در Auto نیز Offline و Manual پشت Official قرار دارند.

چرا صفحه admin فقط state قبلی را نشان می‌دهد؟

باز کردن صفحه تنظیمات نباید خودش request خارجی ایجاد کند؛ status از state محلی خوانده می‌شود.
